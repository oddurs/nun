## Problem

Open buffers need a spatial home, and tabs are the one everybody already knows.

## Proposal

One tab strip per pane. Click to focus, middle-click to close, drag to reorder
within the strip and across panes. Dirty state is a dot, not an asterisk in the
title. Overflow scrolls rather than shrinking labels into illegibility.

## Acceptance criteria

- [x] Reorder by drag, with a visible drop indicator
- [ ] Drag to another pane moves the tab and its full editing state
- [x] Close prompts when the buffer is dirty, and the prompt is clickable
- [x] Labels disambiguate identically-named files by their nearest distinct parent

## 2026-09-19

Criterion 2 — dragging a tab to another pane — needs panes, which are 0020; noted there. Labels come from nun-workspace::tab_labels, which grows only the tabs that clash, one folder at a time. The strip appears with the second file: one file needs no strip and the row is better spent on text. Ctrl+W now closes the tab rather than quitting, and closing the last tab leaves an empty buffer rather than quitting.

## 2026-09-19

Closing the only open file has a mouse path too: with one document there is no strip, so the status line carries the cross. It is a click target but not a hover target — one button is no reason to keep any-motion reporting on all session. Middle-click is gated behind an open prompt or menu, so a tab cannot be closed out from under a question about another tab.
